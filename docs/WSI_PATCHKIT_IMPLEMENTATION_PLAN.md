## 1. 目标与实现路线

交付连续物理坐标精确采样、完整读取结果和资源安全的有界结果流，保留现有合法整数请求的默认输出及 `Patch(request,image)` 构造。

采用增量 API：严格物理请求 → 采样计划 → 现有 reader 区域读取 → 精确重采样与填充 → 完整结果 → 串行/并行流。同步入口是流的唯一采样实现。vendor reader 保持原生区域 IO 职责。

| 阶段                   | 核心交付                                             | 覆盖需求                        | 主要验收                         |
| ---------------------- | ---------------------------------------------------- | ------------------------------- | -------------------------------- |
| 0 契约与基线           | API 契约、兼容策略、独立参考计算、样本清单           | R01–R10 的设计决策             | A01–A16 用例落实到测试清单      |
| 1 请求与采样计划       | 严格请求、输出网格、选层、画布策略、限额预检         | R01/R02/R07/R08/R10 的基础      | A01/A04/A08/A13/A16              |
| 2 精确同步读取核心     | nearest/bilinear、constant、精确 mask、完整结果      | R01/R02/R05；R03/R04/R10 的基础 | A01/A02/A03/A05/A07/A14/A15      |
| 3 插值和填充扩展       | bicubic、reflect、明确的 area 行为、全部读取规模限制 | R03/R04/R08                     | A03/A05/A06/A13/A14              |
| 4 完整结果流与生命周期 | 选层透传、顺序和有界预取、线程归属、异常清理         | R06/R09，贯通其他需求           | A09/A10/A11/A12/A15/A16          |
| 5 库级验收与交付       | 后端校准、兼容回归、文档、示例、版本产物             | R01–R10 库级闭环               | A01–A16                         |
| 6 SlideInfer 接入      | 薄适配、迁移开关、下游等价回归                       | 需求第 8 节的迁移交付           | 坐标/像素/mask/顺序/生命周期回归 |

## 2. 阶段 0：固定契约与验收基线

**工作内容**

1. 恢复并归档原始需求，确定实现使用的版本，保留 R/A 编号用于追踪。
2. 确定公共类型及配置入口：物理请求、输出网格、采样计划、结果、限额和流模式。逐请求可以表达 level/policy，显式 level 优先；若提供流默认配置，明确请求覆盖规则。
3. 固定中心坐标、nearest 半整数取舍、Keys cubic 核、uint8 量化、constant/clamp/reflect 边界规则；明确 native 只接受 nearest。
4. 为新精确入口确定 area 语义。建议采用输出像素物理 footprint 与原生像素单元的面积加权，仅支持 RGB 且两个轴均不放大；确定边界 footprint 处理。旧 helper 保留 Pillow BOX 输出。
5. 确定 max_output_pixels/max_read_pixels 的默认值、显式禁用方式和计数口径。第一版建议单原生区域读取，max_read_pixels 限制该请求实际读框面积，包含插值邻域；超限明确报错。
6. 确定请求迭代器所有权，建议默认借用、显式选项声明拥有；确定清理错误报告机制及 reader 同线程生命周期保障。
7. 确定旧入口校验迁移：合法整数调用维持原结果；旧分数/bool 输入若仍暂时兼容，必须发出明确迁移提示；拒绝时间与版本写入文档。新入口立即严格校验，禁止静默截断。
8. 保存旧 API 的像素参考输出，建立独立的梯度、脉冲、反射和插值参考计算，并列出 PNG、TIFF 金字塔、OpenSlide/KFB 样本与依赖。

**改动与交付物**：新增精确采样 API 契约文档、验收追踪表与参考测试夹具；记录所有未决项的最终选择。

**完成条件**：实现不再依赖未定义的 area、选项优先级、限额或所有权语义；A01–A16 均有明确输入、预期和执行层次。独立参考计算不调用生产采样函数。

## 3. 阶段 1：请求、网格与采样计划

**工作内容**

1. 在 `types.py` 增加物理请求、网格、限额等值对象；保留负数和分数原点，支持非等轴 MPP、source_mpp 和逐请求选层。
2. 提供旧 PatchRequest 的显式转换：origin_um=(x*target_mpp_x,y*target_mpp_y)。转换不能恢复旧构造过程中已经丢失的分数，文档说明应直接使用物理请求。
3. 增加严格校验：坐标有限，MPP 有限且正；整数尺寸/level/限额拒绝 bool 和分数；选项、填充值、派生范围溢出错误包含字段与原因。
4. 实现纯规划入口：按目标中心网格确定原生采样位置、核邻域、原生层整数起点、level-0 IO 起点和读取尺寸；保存输出网格或仿射变换。
5. 输出面积在任何输出/掩码/坐标大数组分配前检查；原生读取面积在 IO 前检查。规划本身不执行像素 IO，也不构造 HW 坐标数组。
6. 统一 round/ceil 画布计算，贯穿 SlideSpec、virtual_canvas_size、网格请求及兼容读取配置；保持 round 默认结果。
7. 复用非整数 downsample 起点转换的已有修复，并扩展 1000/333、800/271、非等轴和多个原生索引用例。

**涉及模块**：`types.py`、新增 `sampling_plan.py`、`geometry.py`、`sampling/grid.py`、`__init__.py`；核查其他 sampler 对配置传播的影响。

**完成条件**：A01/A04/A08/A13 的规划与校验用例通过；非法 level 在 IO 前报错；round/ceil 的构造与读取配置一致；现有构造和默认画布回归通过。

## 4. 阶段 2：精确同步读取核心

**工作内容**

1. 实现 `read_physical_patch_result`，接收或生成阶段 1 计划，调用已有 read_region，再按全局输出中心坐标采样。
2. 实现 nearest 和 bilinear，严格遵守中心索引公式、半整数选择及 `clip(floor(value+0.5),0,255)` 量化。
3. 实现 constant 标量/RGB 填充；有效中心插值的原生核邻域采用 clamp。完全越界 constant 返回固定尺寸填充和全 false mask，不调用 read_region。
4. 按物理半开范围计算 HW bool mask，与 canvas 舍入和插值邻域解耦。宽=3、目标 MPP=2 的末端中心必须无效。
5. 返回 image、valid_mask、grid、source_level 和计划；native/标签只允许 nearest。复用 uint8、灰度 RGB 扩展和 RGBA 白底合成规则，明确拒绝不支持的数据类型。
6. 保证返回数组独立持有数据，后续读取、结束迭代和 reader.close 不使结果失效。
7. 保留旧 helper 的采样和滤波路径；新入口不支持的模式明确报错。

**涉及模块**：新增 `resampling.py`、精确读取模块，`types.py`、`geometry.py`、`__init__.py` 和相关测试。

**完成条件**：需求差异样例的 nearest/bilinear 新结果符合公式；相邻请求的相同物理中心结果一致；A01/A02/A03/A05/A07/A14/A15 对已支持模式通过。PNG/TIFF 的同步基础读取通过，旧 helper 参考输出保持一致。

## 5. 阶段 3：插值、反射与规模限制补齐

**工作内容**

1. 实现 Keys cubic a=-0.5，固定四点轴向邻域、二维核组合、边界处理和量化；用独立参考验证梯度、脉冲和饱和输出。
2. 实现 numpy reflect 对应的不重复端点规则，对整个原生轴的核邻点映射；长度 1 退化复制，远距离越界使用周期映射。
3. reflect 完全越界请求允许读取映射所需像素，但几何 mask 必须全 false；映射后规划读框，避免把远距离原点直接纳入 IO 包围框。
4. 按阶段 0 契约实现或明确分配新旧入口的 area 能力；若新入口支持 area，验证任意相位和边界规则，不能以整数包围框 BOX resize 冒充精确采样。
5. 为所有插值/填充模式执行统一限额检查；错误包含请求、所选层、实际输出/读取尺寸和上限，核邻域计入读取面积。
6. 对 native 模式明确 dtype、通道与填充值约束；完全越界结果利用可靠元数据确定格式，无法确定时给出可定位的错误。

**完成条件**：A03/A05/A06/A13/A14 完整通过；各模式有明示的支持范围；超限在分配或 IO 前失败；所有新增模式保留相邻请求的采样相位一致性。

## 6. 阶段 4：完整结果流与生命周期

**工作内容**

1. 扩展 Patch 可选结果字段或增加完整结果流；兼容 `Patch(request,image)` 及既有 request/image 访问，精确模式统一调用同步入口。
2. 传递逐请求 level/policy、插值、填充及限额，确保多切片/不同原生层请求可正确执行；保留各 worker 独立 reader 和元数据缓存。
3. 保持按输入顺序产出和 max_pending 上限：计数包含排队、执行、完成等待与当前 yielded 请求，下一次消费前不补交当前容量。
4. 让自有 reader 的创建、读取与关闭发生在所属 worker。可采用固定 worker 循环与有界任务/结果机制；清理任务必须有确定线程归属。
5. 空流延迟创建 reader；借用 reader 不关闭；拥有的请求迭代器在正常结束、失败和提前关闭时执行 close。
6. 关闭时取消未开始任务，等待已开始 native IO 完成；原始读取/生成异常优先，成功执行后的清理异常传播，其他清理错误可追踪。
7. 明确按序 Future 等待可能延迟后续错误暴露，提供 `with/contextlib.closing` 示例；不承诺强制中断第三方 IO。

**涉及模块**：`stream.py`、结果类型、公共导出和流测试；回归 `torch/dataset.py`，保持默认数据项结构。

**完成条件**：A09–A12/A15/A16 通过。覆盖 factory/read/请求生成/close 错误组合、慢消费者、max_pending=1、小于 worker 数、乱序完成、提前关闭、线程 ID 与结果持久性；直接、串行流和并行流的图像/mask/grid/source_level 一致。

## 7. 阶段 5：后端校准、回归与库级发布

**工作内容**

1. 用 PNG、真实 TIFF 金字塔验证输出相位、源层起点、非等轴 MPP 和边界；用代表性 OpenSlide/KFB 多层样本校准 metadata 声明的网格与实际 read_region 返回像素。
2. 后端映射不一致时局部修改 reader 适配层，保留 read_region 公共签名和原生语义；重复相关旧 API 和新采样回归。
3. 执行 A01–A16 追踪表、旧 helper 像素回归、所有相关既有测试，并完成全量测试；排查已有全量测试停滞后再给出全量结论。
4. 更新 README、CHANGELOG、API 契约，提供同步、串行流、并行流和旧请求迁移示例；明确默认限额、禁用方式、结果所有权及各模式数据类型限制。
5. 通过 uv 构建分发产物，并在隔离 uv 环境做安装和示例 smoke 验证；核查公共导出及可选依赖。

**完成条件**：所有库级需求均有代码、测试和文档证据。缺失 vendor 样本时，记录具体未验收后端与场景；不将核心/模拟测试通过等同于全部 backend 验收。形成可审查的版本产物和迁移说明，发布动作遵循项目发布流程。

## 8. 阶段 6：SlideInfer 适配与迁移

**前置条件**：阶段 5 的库级交付可用，且获得 SlideInfer 工作区和相关样本。该阶段需在下游项目执行。

**工作内容**

1. 将内部连续物理请求映射到新请求，透传 source_mpp、选层、插值、填充和限额；由库返回完整结果。
2. 保留 SlideInfer 的 ROI、valid_region_sample、ownership、context/halo、chunk 规划和推理逻辑；在适配层将 geometry_valid 与任务掩码相交。
3. 保留迁移开关，以相同配置比较迁移前后的坐标、图像、掩码、原生层、顺序和资源释放；量化后的 uint8 按契约逐像素比较，浮点几何使用预先定义的容差。
4. 完成各公开配置组合和代表性任务回归，再移除重复采样算法与通用调度代码；保留可回退的迁移版本。

**完成条件**：接入结果满足公式和下游回归，而非仅完成导入替换。所有公开选项要么正确执行，要么按约定明确拒绝；没有静默降级。

## 9. 测试、拆分与里程碑

开发环境统一由 uv 管理，使用项目 `.venv/bin/python`，测试使用 `.venv/bin/python -m pytest`。规划、核参考、同步读取、流生命周期、后端和下游分层验证；固定 uint8 输出逐像素比较，浮点几何容差在阶段 0 固定。

建议按阶段组织审查；阶段 3 可拆为 bicubic/reflect 和 area/格式/限额两组，阶段 4 可拆为完整结果透传和生命周期两组。每组提交同时包含对应测试和使用说明。每阶段结束运行针对性回归，阶段 5 完成全量和安装验证。
